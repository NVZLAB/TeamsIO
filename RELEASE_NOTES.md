# TeamsIO 1.0.1

- Public presence board with organization-configurable tenant, client, and group IDs.
- First-run setup and right-click connection settings.
- Double-click a person to open a Teams chat.
- GitHub Releases updates with SHA-256 verification.
- Themes, sorting, copying, window preferences, and always-on-top support.

- New person-and-ring app, taskbar, and installer icon.
- Offline first-run app registration guide, Microsoft documentation links, and inline ID instructions.

- Patched vulnerable Kiota dependencies and updated the bundled .NET security runtime.
- Restricted update redirects, bound assets to release tags, and added locked verification before installer launch.
- Reduced profile permission to User.ReadBasic.All and updated the setup guide.
- Added dependency locks, publication checks, secret scanning, and release validation.
